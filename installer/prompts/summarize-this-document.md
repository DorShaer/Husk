name: summarize-this-document
description: TL;DR of a long doc, paper, article, transcript, or RFC. Three layers: one-line takeaway, key points, and details only if I ask.
---

Summarize the document I share into three layers.

If I have not shared the doc yet, ask me ONE short question:
  "Paste the text or share a file path / URL?"
and wait.

Once you have it, write the summary in this exact shape:

**TL;DR** (one sentence, the single thing I should know if I read nothing else)

**Key points** (5 to 8 bullets, each one short and self-contained, no nesting, no marketing language)

**Sections** (one short paragraph per section or major argument, in original order)

Then stop. Do not add "let me know if you want more": I will ask if I do.

Rules:
- No filler. No "the document discusses".
- Quote a phrase only when its exact wording matters.
- If the doc has data (numbers, dates, names), pull them out. Don't paraphrase a number into "several".
- If anything is unclear in the source, say "unclear:" with what is unclear. Don't invent.
