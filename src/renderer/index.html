      Configure custom orchestrator agents

      Pick which model runs simple vs complex tasks for your agent. Leave on Automatic and Husk selects for you, and tells you why in the run log.

      Install MCP servers from repo

      Point Husk at a cloned repo that ships an mcp-servers/ directory. Each subfolder with a package.json is offered as a separate server. Husk will build it when needed and write the right entry into the active CLI's MCP config. Claude and Copilot get a real config write; Codex and Aider get a snippet you can paste.

      Install agent pack from repo

      Point Husk at a cloned repo that ships an agents directory (.github/agents/ or agents/). Picked agents are installed into every AI tool you have (Claude, Copilot, ...) using each tool's native agents folder. Your working directory is unchanged; if an agent reads a relative skills/<id>/SKILL.md, point Preferences › Working directory at that repo.
